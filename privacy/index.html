Privacy

Privacy Policy

Last updated: July 23, 2026.

AddTextToGif.net is designed as a browser-local GIF text editor. The selected GIF, filename, text layer content, preview frames, and exported GIF are processed in your browser and are not uploaded by this site.

What We Collect

The MVP does not use analytics, accounts, comments, cloud storage, advertising scripts, or server-side uploads. We do not intentionally collect GIF files, filenames, text content, or generated output files.

Local Browser Processing

Your browser reads the GIF into memory, decodes frames, draws text layers, and creates a downloadable file. Temporary object URLs and in-memory frame data are cleared when you reset the editor, close the tab, or the browser releases the page.

Network Requests

The page loads static site files, scripts, styles, icons, the optional sample GIF, and the open graph image from this domain. The editor does not send your selected file or text layers to a server.

Contact and Deletion

Because the editor does not store uploaded GIFs or generated files, there is no stored output for us to delete. If a future version adds optional storage or analytics, this policy must be updated before launch.
